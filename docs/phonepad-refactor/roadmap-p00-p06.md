# Cobertura de entrega P00–P06, incluida P01A

Actualización: 21/09/2026. Base confirmada: `880d0bb`, rama `refactor/p00-baseline`, árbol limpio al comenzar. Las instrucciones de ejecución del usuario reemplazan las campañas y delegación anteriores. P07–P12 siguen fuera del alcance.

Esta es la única checklist vigente. Se conservan los 77 IDs y sus criterios originales para no ocultar diferencias. Los informes históricos y la investigación se conservan como antecedentes; no representan el estado actual. Una prueba automatizada no equivale a aceptación física.

## Verificación y entrega

- Go con detección de carreras; TypeScript; suites móviles, web y Python. Las regresiones cubren Unicode, recibos, lotes, sesión, gestos, permisos y lifecycle.
- Candidato móvil 1.0.1, build 5. No se distribuye por OTA a runtimes anteriores con dependencias nativas distintas.
- Servidor y receptor web con activación reversible en `setup/activate-release.py`; `tools/hfr/stage_release.py` incluye dependencias completas.
- GitHub autorizado: `https://github.com/lucasscognamiglio9/phonepad.git`. `origin` local no se usa para push.
- El manifiesto local de entrega registra commit, fingerprints, hashes, resultados de build y activación. Ninguna fase se declara completa antes de su aceptación requerida.

## Aceptación final agrupada y recursos

1. iPhone: Mac con Xcode 26.4+, CocoaPods y firma autorizada para `mobile/scripts/build-ios-personal.sh`, instalación de 1.0.1 (5). No se asume acceso ni se autoriza un gasto cloud.
2. Sobre ese candidato y el host actualizado: texto Unicode/largo, dictado/selección, recibo incierto sin duplicación, atajos/repetición, lote mixto ordenado y publicación completa, clipboard en ambos sentidos.
3. Misma sesión: Directo/Trackpad, calibración a 1–2 pasadas y blancos lentos, cursor real, doble toque/arrastre/derecho/scroll; zoom/pan con teclado, giro y retorno, revocación/reconexión, pantalla activa y restauración al salir.
4. Android, iPad/tablet y Safari: dispositivos disponibles para instalación y aceptación. Las verificaciones en Chromium no sustituyen esas plataformas.

P00, P01, P01A, P02, P03, P04, P05 y P06 permanecen abiertas mientras conserven aceptación, recursos o criterios funcionales pendientes. En particular, P04.2 conserva explícitamente la diferencia entre el cursor incorporado entregado y el overlay independiente previsto anteriormente.
