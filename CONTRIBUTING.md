# Contribuir

Para un cambio grande, abrí primero un Issue que explique el problema. Para una corrección pequeña, enviá un pull request con los pasos para reproducirlo y las comprobaciones realizadas.

Seguí la [guía de desarrollo](docs/desarrollo.md). Conservá los borradores y transferencias durante cambios de sesión. Los reintentos no deben duplicar texto, pegados ni archivos.

Indicá qué comprobaste con tests y qué probaste entre dispositivos. Para un cambio visual, adjuntá una captura sin datos personales. Las pruebas de instalación, permisos y video en Mac y Windows siguen pendientes en equipos reales.

Para fallos de seguridad, seguí [SECURITY.md](SECURITY.md).
