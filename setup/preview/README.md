# Operational guardrails

Production uses the authorized portal capture path. Do not create, clone, disable or restore virtual monitors on the live desktop for performance testing: the September 10 experiment triggered GNOME 50.1 SIGSEGV and terminated the user session. Virtual-display experiments must be isolated from the working compositor. Synthetic encoder throughput is not native-device FPS or evidence of stability.

Keep verified startup-keyframe recovery and the five-minute paused-session lease. Do not promote a new encoder/capture route without stop, suspend/resume, authorization and actual receiver validation. Current production is deliberately the pre-experiment rtc.py.
