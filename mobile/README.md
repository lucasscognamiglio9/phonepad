# PhonePad para iPhone

App React Native con Expo SDK 57, teclado nativo, controles multitáctiles y receptor WebRTC. Usa el equipo HTTPS elegido en el selector; guardar una dirección no concede acceso al servidor.

El borrador permanece en el teléfono hasta tocar Enviar. La rotación conserva el editor y el video. Los adjuntos se copian al almacenamiento de la app antes de transferirlos; un resultado incierto requiere revisión para evitar duplicados.

La barra del teclado permite pegar en el borrador y copiar texto entre los portapapeles de ambos equipos. Enviar texto conserva el contenido anterior del portapapeles de la computadora. [Acciones y límites](../docs/portapapeles.md).

Para instalar, compilar o comprobar el cliente, seguí las guías de [instalación](../docs/instalacion.md) y [desarrollo](../docs/desarrollo.md). Expo Go no incluye el receptor nativo que necesita PhonePad.

La configuración pública no está vinculada a una cuenta Expo ni descarga actualizaciones de un canal personal. Los cambios nativos requieren un build nuevo.
